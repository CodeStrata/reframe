Customer Account Self-Service

J01 View an account

Card services agent · Look up an account by number and see its balances, limits, dates and the customer's profile while the caller waits.

  1. Login Screen COSGN0A: Sign in with user ID and password
  2. Main Menu COMEN1A: Choose option 1, Account View
  3. View Account CACTVWA: Enter the 11-digit account number and press Enter
  4. View Account CACTVWA: Fix the account number if an error is shown, then read the account and customer details
  5. Main Menu COMEN1A: Press F3 to return to the main menu

Card services agent · Change an account's and its customer's details after confirming the caller, saving only valid, confirmed changes.

  3. Update Account CACTUPA: Enter the account number and press Enter to fetch the account and customer
  4. Update Account CACTUPA: Type the changes to account and customer fields and press Enter to check them
  5. Update Account CACTUPA: Correct any field the error message points to and press Enter again
  6. Update Account CACTUPA: Press F5 to save the changes, or F12 to cancel them
  7. Main Menu COMEN1A: Press F3 to return to the main menu

J17 Remove a user

Administrator · Find a user who should no longer have access and delete their profile so they can no longer sign in.

  1. Login Screen COSGN0A: Sign in with an administrator user ID and password.
  2. Admin Menu COADM1A: Enter option 1 (User List) and press Enter.
  3. List Users COUSR0A: Find the user, paging with F7 and F8 if needed, type D next to them and press Enter.
  4. Delete User COUSR3A: Check the user's name and type, which are filled in, to make sure it is the right person, then press F5 to delete them.
  5. Delete User COUSR3A: If the user ID is empty or not found, correct it, press Enter to look the user up again, then press F5.
  6. Admin Menu COADM1A: Press F3 to go back to the admin menu.
