# Feature specification: Translate workload simulator scripts

**Feature:** UP-C02 · Unassigned-Programs · Programs not in a business function

**Status: DRAFT**: the function is not signed off yet. Confirm with the owner before building to it.

## User scenarios and testing

### User story (UP-C02)

As a workload simulator operator, I want each simulator script member translated in the script translation job, so that the scripts are ready to drive simulation runs and their listings can be checked.

Translates each of the 20 workload simulator scripts in the script library so they are ready to drive simulation runs. Each script's translation listing is kept for the operator to check. It must translate every listed script, never change the script or message libraries, and leave no work files behind.
