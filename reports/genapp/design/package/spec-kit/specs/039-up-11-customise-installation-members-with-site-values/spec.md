# Feature specification: Customise installation members with site values

**Feature:** UP-C11 · Unassigned-Programs · Programs not in a business function

**Status: DRAFT**: the function is not signed off yet. Confirm with the owner before building to it.

## User scenarios and testing

### User story (UP-C11)

As an installer, I want placeholders in the GenApp installation members replaced with my site's configured values, so that the members can be used in my environment.

Fills in the placeholders in the GenApp installation templates with the values the installer configured for their site, so the templates work in that environment. The placeholders stand for library names, region and system identifiers, database names and file paths. Every placeholder must get the value of its own setting and none may be left behind. '<WSIMLOG>', '<WSIMSTL>', '<PDSMACP>', '<PDSDBRM>' and '<PDSMSGS>' must take the simulator product qualifier, as they do today, not the library name they suggest.

## Requirements

### Functional requirements

- **UP-REQ-F-057** (historical artifact): The system shall replace every occurrence of the placeholder '<WSIMLOG>' in each member it edits with the workload-simulator high-level qualifier (WSIMHLQ, e.g. 'PP.WSIM.V110'), not with the log data set name. Rules: UP-BR-079.
- **UP-REQ-F-058** (design note): The system shall replace every occurrence of the placeholder '<LOADX>' in each member it edits with the GenApp load library name (LOADX, the installation qualifier followed by '.LOAD'). Rules: UP-BR-080.
- **UP-REQ-F-059** (design note): The system shall replace every occurrence of the placeholder '<AORSYSID>' in each member it edits with the application-owning region system identifier (AORSYSID). Rules: UP-BR-081.
- **UP-REQ-F-060** (design note): The system shall replace every occurrence of the placeholder '<DB2RUN>' in each member it edits with the configured database run library value (DB2RUN). Rules: UP-BR-082.
- **UP-REQ-F-061** (design note): The system shall replace every occurrence of the placeholder '<TORAPPL>' in each member it edits with the terminal-owning region application identifier (TORAPPL). Rules: UP-BR-083.
- **UP-REQ-F-062** (design note): The system shall replace every occurrence of the placeholder '<SOURCEX>' in each member it edits with the GenApp source library name (SOURCEX, the installation qualifier followed by '.SRC'). Rules: UP-BR-084.
- **UP-REQ-F-063** (design note): The system shall replace every occurrence of the placeholder '<TORSYSID>' in each member it edits with the terminal-owning region system identifier (TORSYSID). Rules: UP-BR-085.
- **UP-REQ-F-064** (design note): The system shall replace every occurrence of the placeholder '<ZFSHOME>' in each member it edits with the configured file-system home directory (ZFSHOME). Rules: UP-BR-086.
- **UP-REQ-F-065** (design note): The system shall replace every occurrence of the placeholder '<DB2DBID>' in each member it edits with the configured database name (DB2DBID). Rules: UP-BR-087.
- **UP-REQ-F-066** (design note): The system shall replace every occurrence of the placeholder '<WSIMMSX>' in each member it edits with the GenApp message-text library name (WSIMMSX, the installation qualifier followed by '.MSGTXT'). Rules: UP-BR-088.
- **UP-REQ-F-067** (design note): The system shall replace every occurrence of the placeholder '<DORAPPL>' in each member it edits with the data-owning region application identifier (DORAPPL). Rules: UP-BR-089.
- **UP-REQ-F-068** (design note): The system shall replace every occurrence of the placeholder '<CICSHLQ>' in each member it edits with the configured transaction-server library prefix (CICSHLQ). Rules: UP-BR-090.

- **UP-REQ-F-071** (design note): The system shall replace every occurrence of the placeholder '<WSIMHLQ>' in the member being customised with the site's workload simulator library qualifier (WSIMHLQ). Rules: UP-BR-093.
- **UP-REQ-F-072** (design note): The system shall replace every occurrence of the placeholder '<USRHLQ>' in the member being customised with the installing user's data set qualifier (USRHLQ). Rules: UP-BR-094.
- **UP-REQ-F-073** (design note): The system shall replace every occurrence of the placeholder '<WSIMWSX>' in the member being customised with the name of the GenApp workload simulator script library (WSIMWSX), leaving a member without the placeholder as it is. Rules: UP-BR-095.
- **UP-REQ-F-074** (design note): The system shall replace every occurrence of the placeholder '<SQLID>' in the member being customised with the Db2 SQL authorisation ID set for the installation (SQLID). Rules: UP-BR-096.
- **UP-REQ-F-075** (design note): The system shall replace every occurrence of the placeholder '<CPSMHLQ>' in the member being customised with the site's CICSPlex SM library qualifier (CPSMHLQ). Rules: UP-BR-097.
- **UP-REQ-F-076** (design note): The system shall replace every occurrence of the placeholder '<DB2CCSID>' in the member being customised with the Db2 coded character set ID set for the installation (DB2CCSID). Rules: UP-BR-098.
- **UP-REQ-F-077** (design note): The system shall replace every occurrence of the placeholder '<DB2PLAN>' in the member being customised with the Db2 plan name set for the installation (DB2PLAN). Rules: UP-BR-099.
- **UP-REQ-F-078** (historical artifact): The system shall replace every occurrence of the placeholder '<PDSMACP>' with the workload simulator library qualifier (WSIMHLQ), not with a map copybook library name, noting that no supplied install member contains this placeholder. Rules: UP-BR-100.
- **UP-REQ-F-079** (historical artifact): The system shall replace every occurrence of the placeholder '<PDSDBRM>' with the workload simulator library qualifier (WSIMHLQ), not with the DBRM library name, noting that no supplied install member contains this placeholder. Rules: UP-BR-101.

- **UP-REQ-F-081** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<AORAPPL>' with the configured application-owning region application name (AORAPPL). Rules: UP-BR-103.

- **UP-REQ-F-085** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<DBRMLIX>' with the unquoted name of the GenApp Db2 DBRM library (DBRMLIX). Rules: UP-BR-107.
- **UP-REQ-F-086** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<CICSLIC>' with the configured name of the CICS licence data set (CICSLIC). Rules: UP-BR-108.
- **UP-REQ-F-087** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<CSDNAME>' with the configured CICS system definition (CSD) data set name (CSDNAME). Rules: UP-BR-109.
- **UP-REQ-F-088** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<WUIAPPL>' with the configured CICSPlex SM web user interface application name (WUIAPPL). Rules: UP-BR-110.
- **UP-REQ-F-089** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<MAPCOPX>' with the unquoted name of the GenApp map copybook library (MAPCOPX). Rules: UP-BR-111.
- **UP-REQ-F-090** (design note): When a GenApp installation member is customised, the system shall replace every occurrence of the placeholder '<CMASAPPL>' with the configured CICSPlex SM address space (CMAS) application name (CMASAPPL). Rules: UP-BR-112.
- **UP-REQ-F-091** (design note): When an installation member is customised, the system shall replace every occurrence of '<DORSYSID>' with the data-owning region system identifier the installer set (DORSYSID, shipped as 'DOR1'). Rules: UP-BR-113.
- **UP-REQ-F-092** (historical artifact): When an installation member is customised, the system shall replace every occurrence of '<PDSMSGS>' with the Workload Simulator product qualifier (WSIMHLQ, shipped as 'PP.WSIM.V110'), not with the GenApp messages library name, noting that no shipped member contains this placeholder. Rules: UP-BR-114.
